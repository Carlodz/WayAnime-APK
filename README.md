# WayAnime APK

## المجلدات الجاهزة (حط فيها الملفات من الـ zip):

- `www/` — index.html, renderer.js, android-api.js, CSS, JS…
- `www/assets/` — صور، أيقونة، فيديو
- `www/assets/icons/` — أيقونات SVG
- `www/assets/logos/` — شعارات الأنمي
- `www/fonts/` — خطوط NotoSans
- `www/tools/` — diag.js
- `native/` — ملفات Java (MainActivity, ImmersivePlugin…)
- `assets/` — app-icon.png
- `tools/` — أدوات إضافية

## بعد الرفع:
1. Actions → **Build Android APK** → Run workflow
2. نزّل الـ APK من Artifacts
