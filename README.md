# WayAnime — نسخة الأندرويد (Capacitor)

نفس واجهة ومزايا نسخة الديسكتوب (+ المانجا)، لكن كتطبيق أندرويد. الواجهة (`index.html` + `renderer.js` + `manga.js` + `watchparty.js`) **ما تغيّرت**؛
الذي تغيّر هو الطبقة اللي تحت: `www/android/bridge.js` يشغّل منطق `main.js` الأصلي (حاليًا في `www/logic/main.js`) داخل التطبيق ويقدّم `window.api` بنفس الشكل القديم.

## البناء (اختر طريقة)
**1) GitHub Actions (بدون تثبيت أي شيء):** ارفع المجلد كاملًا لمستودع GitHub ← تبويب Actions ← *Build WayAnime APK* ← حمّل `WayAnime.apk` من Artifacts وثبّته.

**2) على جهازك:** تحتاج Node 20 + JDK 17 + Android SDK (Android Studio).
```
npm install
npm run android:init     # مرة واحدة: ينشئ مجلد android/ ويطبّق البروكسي والأيقونات
npm run android:apk      # الناتج: android/app/build/outputs/apk/debug/app-debug.apk
```
بعد أي تعديل في `www/`: `npm run android:sync` ثم ابنِ من جديد. للفحص السريع للجسر: `npm test`.

## ما يعمل
أنمي (Animeify / WitAnime / Stardima مدبلج / أنمي أضفته)، البحث والفلاتر، المانجا (MangaDex + مانجا ليك)، المفضلة وسجل المشاهدة، حساب موقع البطاقات + المزامنة،
الترجمة، AniList (وصف/شخصيات/أجزاء)، حل السيرفرات، المشاهدة المشتركة، التحميلات (ملفات mp4 المباشرة)، إشعارات الحلقات الجديدة (أثناء فتح التطبيق).
الفيديو وصور المانجا تمرّ عبر بروكسي محلي (`native/MainActivity.java`) ليضيف الـ Referer المطلوب ويعيد كتابة روابط HLS.
زر الرجوع في الجهاز يغلق النوافذ/المشغّل ثم يرجع للخلف ثم للرئيسية ثم يخرج. الشريط السفلي يحل محل القائمة العلوية (مع تبويب «المانجا»).

## ما لا يعمل على الأندرويد
- **التورنت** و**تحويل الفيديو (ffmpeg)**: يظهر للمستخدم خطأ واضح؛ اختر سيرفراً آخر.
- **تحميل HLS (m3u8)**: غير مدعوم (mp4 فقط).
- **Discord Rich Presence** والـ tray والتشغيل في الخلفية: خاصة بالديسكتوب.
- صفحات السيرفرات المضمّنة (iframe) قد ترفض العرض داخل التطبيق؛ أقرب بديل زر «فتح في المتصفح».
- مانجا ليك إذا فعّلت Cloudflare تحدّيًا: على الديسكتوب كان يُحلّ بنافذة مخفية، وهنا قد يفشل الطلب أحيانًا.
- إشعارات الحلقات في الخلفية تحتاج خدمة أصلية (غير مضمّنة).

## إعدادات
`www/android/config.js`: `UPDATE_REPO` (مستودع GitHub لزر «تحديث» — يبحث عن `.apk` في آخر Release).
عنوان موقع البطاقات في `www/logic/main.js` (`CARDS_SITE`).

## واجهة البداية والتنقل
- عند فتح التطبيق: شاشة `#splash` (صورة `assets/hero-bg.jpg` كاملة + اللوغو) تبقى حتى تتحمّل قائمة «آخر الحلقات» (حدّ أدنى 1.6 ث، أقصى 15 ث) — `www/android/splash.js`.
- (البانر محذوف) بعدها تظهر واجهة «آخر الحلقات» (`arLatest` في `renderer.js`).
- زر «الرئيسية» يفتح صفحة `arHome`: الأكثر شعبية ← الأعلى تقييماً ← يُعرض حالياً ← مدبلج ← التصنيفات (زر «عرض الكل» وزر التصنيف يفتحان صفحة التصفح بالفلاتر).
- زر الرجوع (في التطبيق أو في الجهاز) يرجع إلى «آخر الحلقات»، ومنها يخرج من التطبيق.

## الرئيسية المخصصة للهاتف (جديد)
زر «الرئيسية» يفتح الآن واجهة مصمّمة للهاتف: `www/android/home.js` (المنطق) + آخر قسم في `www/android/mobile.css` (`.mh`). الواجهة القديمة بقيت كاحتياط (`arHomeClassic` في `renderer.js`).
- شريط أقسام ثابت تحت الهيدر: يقفز للقسم ويتلوّن حسب مكانك في الصفحة.
- «متابعة المشاهدة»: من سجل الاستئناف المحفوظ، مع شريط تقدّم، والضغط يفتح الحلقة من حيث توقفت.
- «المميّز»: شرائح تُسحب أفقياً (6 أنميات) — لإخفائه غيّر `MH_FEATURED` في `home.js` إلى `false`.
- صفوف أفقية (شعبية ← تقييم بأرقام ترتيب ← يُعرض حالياً ← مدبلج) بهياكل تحميل، وزر «إعادة المحاولة» لكل صف إذا فشل.
- التصنيفات: ثلاثة صفوف تُسحب أفقياً بدل قائمة طويلة.
